# Catch up: Python + SQL, from zero to a full project

One file per topic. Every file has 3 parts:

1. EXAMPLES: working code. Type it out yourself, run it, change things.
2. EXERCISES: practice on that topic only.
3. PROJECT STEP: one piece of a mini bank app. Each step builds on the last one.
   By file 15 you will have a full app: classes, files, and a SQLite database.

Run any file with:  python3 01_variables_scope.py

Stuck? Answers are in solutions/. Try first, then compare.

| # | File | Topic |

| 02 | 02_strings.py | indexing, slicing [::-1], f-strings, find, replace, split, join |
